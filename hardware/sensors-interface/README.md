# P3 · 传感器 / L1 接口板 / Sensors & L1 Interface

承载样机的**感知侧接口**：外置 IMU（若用）、轮速传感器信号调理，以及 UniLiDAR L1 的转接与减振安装。目标是把"飞线与裸模块"变成**可靠、低噪声、可复现**的感知前端。

> 状态：设计文档。可与 P0 板合板（感知+控制一体），或作为独立小板。KiCad/EasyEDA 工程待绘制。

## 1. IMU 接口（对应 `attitude_filter` / `car_balancer`）

IMU 姿态精度直接受**振动**与**电源噪声**影响——`attitude_filter` 费劲滤掉的很多高频分量，本可以从机械与 PCB 层面就压下去。

- **IMU 选型**：车规/工业级 6 轴（ICM-20689 / ICM-42688-P），带 DMP 更好。
- **减振安装**：PCB 与机架间加硅胶柱/阻尼垫；IMU 远离电机与电源。
- **信号调理**：板载 LDO 独立给 IMU 供电 + π 型滤波；I²C/SPI 上拉与走线屏蔽；可选板载陀螺温度补偿参考。
- **刚性**：IMU 与车体刚性连接，避免柔性支架引入额外相位（滤波会误判为姿态变化）。

## 2. 轮速传感器接口（对应 `W` 轮速输入）

- **类型**：霍尔 / 磁编码器 / 光电。
- **调理**：施密特触发整形、上拉/下拉、RC 去抖；若正交编码器，预留 A/B 解码（MCU 定时器/PCNT）。
- **ESD**：输入端 TVS + 串联电阻，防电机侧耦合。

## 3. UniLiDAR L1 转接 / 安装板

- **供电**：输出 **6 W**；电压官网未标注，**按实物线标确认后再定电源树**（勿想当然），带反接/TVS 保护。
- **数据**：L1 原生 **TTL UART**——板上做 UART breakout（ESD 保护），可选板载 USB 转串口桥（CH340/CP2102 类），直出 USB 接香橙派 `/dev/ttyUSB0`（2 Mbps，需实测转接芯片在该波特率下的稳定性）；以太网 UDP 为备选路径，不做默认支持。
- **机械**：刚性减振支架，保证雷达相对车体位姿稳定（预瞄几何换算依赖此基准）；标注安装基准面与螺孔位。
- **说明**：本板是主动悬架样机的**物理集成件**，`unilidar-driver` 仓库（纯软件驱动）仅引用此处，不重复放硬件。

## 4. 设计要点

- 感知侧与驱动侧**电气隔离**，避免舵机噪声串入 IMU/轮速。
- 板上预留测试点（I²C/SPI、轮速、L1 电源）便于联调。
- 标注所有接插件 pinout 与线序，避免错插。

## 5. 打样与测试清单

- [ ] IMU 上电测噪声（静置时陀螺零偏与方差）
- [ ] 轮速信号在电机运行下整形正常（示波器看边沿）
- [ ] L1 上电并出点云（与 香橙派 联调）
- [ ] 整车振动下对比减振前后姿态解算方差
