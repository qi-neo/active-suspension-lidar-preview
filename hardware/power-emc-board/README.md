# P1 · 电源 / EMC 板 / Power & EMC Board

为样机提供**集中、干净、抗扰**的供电，隔离"舵机大电流"与"香橙派算力 / 传感"两侧。这是主动悬架样机稳定运行的底层保障——舵机（尤其是 4 路同时动作）的电流尖峰会直接通过共地耦合进 香橙派 与 IMU，造成控制抖动甚至复位。

> 状态：设计文档。BOM 见 [`bom.md`](bom.md)。KiCad/EasyEDA 工程待绘制。

## 1. 供电架构

```
外部 12–24 V 电池 / 电源适配器
   │  反接保护 (P-MOS) + 自恢复保险丝
   ▼
[ 电源/EMC 板 ]
   ├─ 舵机轨 (12–24 V 直供，大电流铺铜 + 缓冲)
   ├─ DC-DC 降压 → 5 V / 3 A  → 香橙派 (USB-C PD 或直供)
   ├─ DC-DC 降压 → 3.3 V / 1 A → MCU / 传感逻辑
   └─ 共模扼流 + π 型滤波 + TVS 钳位
```

## 2. 设计要点

- **反接保护**：P 沟道 MOSFET 理想二极管拓扑，压降小、无保险丝烧毁风险；或肖特基 + 保险丝。
- **保险丝 / 自恢复**：总线入口自恢复保险丝；舵机分支可各加保险。
- **DC-DC 选型**：同步降压（MP2307/MP1584 类），效率 >90%；输入输出各加 ≥100 µF 电解 + 10 µF/0.1 µF 陶瓷组合。
- **隔离与单点接地**：舵机功率地、逻辑地、屏蔽地**单点连接**（0 Ω 电阻或磁珠桥接），避免地环路把尖峰灌入敏感电路。
- **EMC**：电源入口共模扼流圈 + π 型滤波；舵机电缆用屏蔽双绞，屏蔽层在板端单点接屏蔽地；TVS 防浪涌。
- **浪涌 / 热插拔**：大电容缓启动，避免上电瞬间电流尖峰触发保护。
- **散热**：降压 IC 加铺铜/过孔散热，必要时散热片。

## 3. 与 P0 板配合

- 本板输出 5 V / 3.3 V / 舵机轨 给 P0 主控板；P0 板负载侧仅做局部稳压与去耦。
- 急停 MOSFET 可放在本板（由 P0 板/急停钮控制栅极），统一在电源侧断舵机供电。
