# P0 主控 + 执行一体化板 BOM（草案）

> 草案，基于 STM32G4 + 数字隔离 + **4 路 PWM 舵机驱动（RDS3115）** + 硬件急停。LCSC 编码为常见参考，下单前按封装/库存复核。
>
> ⚠️ **v0.2 修订**：舵机实测为 PWM 控制（RDS3115 mg），原方案的 4 路 MAX485/RS485 半双工总线**已移除**——
> PWM 舵机不需要收发器与方向切换，改用 MCU 定时器 4 路 PWM 直驱 + 串阻/TVS 保护。
